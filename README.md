# Mekong Sense — Open Transboundary Hydrological Data Portal

Public interactive showcase for the **Mekong Sense** satellite-to-hydrology data ecosystem (Branches B01–B03 operational, B04 validated):
- **B01 — Mekong Cascade Dams Telemetry:** 419 Mekong dams (`H`, `A`, `V`, `Qin`, `Qout`) derived from Sentinel-1 SAR, Sentinel-2 MSI, Landsat-8/9, NASA SWOT KaRIn, and ICESat-2 ATL13.
- **B02 — Calibrated Basin Precipitation:** 16 Mekong sub-basins across 1,339 continuous days with 3-layer bias correction (DBS Gamma + GPD + QDM).
- **B03 — Tonle Sap Storage & Inundation Dynamics:** Flooded forest SAR extraction, SWOT KaRIn WSE alignment, and reverse pulse hydraulics.
- **Standard Model Exports:** Export ready-to-run boundary conditions for DHI MIKE 11 (`.dfs0`), Open TELEMAC (`.qsl`), MRC IQQM (`.dat`), SWAT+ (`.pcp`), GeoJSON, and CSV.
