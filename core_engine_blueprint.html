Hydro-Remote Sensing Computational Pipeline

Profile-Driven Core Engine

Core Engine executes a 4-step physics-anchored pipeline that reconstructs continuous, geodetically consistent hydraulic time series (H, A, V, Qin, Qout) for Mekong basin reservoirs.

01

Multi-Sensor Earth Observation

  • ▪
    Optical (Sentinel-2, Landsat): MNDWI index & Otsu adaptive thresholding for surface area Aobs.
  • ▪
    Radar SAR (Sentinel-1): HAND mountain shadow mask & Dempster-Shafer evidential classification.
  • ▪
    Altimetry (SWOT, ICESat-2): Geoid-referenced water surface height Halt anchored to dam reach.
Input: S1, S2, Landsat, SWOT Yield: Aobs(t), Halt(t)
02

Geodetic Bathymetry & Invariant

  • ▪
    Physical Consistency: Monotonic shape-preserving PCHIP spline dV/dE ≡ Aphys(E).
  • ▪
    Zero Inversion Mismatch: Guarantees derivative of storage curve strictly matches observed area.
  • ▪
    Elevation Bounds: Bound by Dead Water Level (DWL) ≤ H(t) ≤ Normal Pool Level (NPL) ≤ Dam Crest.
Invariants: dV/dE ≡ A(E) Zero Inversion Mismatch
03

Catchment Hydrology & Routing

  • ▪
    Rainfall Forcing: GPM IMERG + ERA5-Land fusion with 3-layer WMO bias adjustment.
  • ▪
    Cascade Delay: Hydrodynamic travel lag τ = L / v between cascaded reservoirs.
  • ▪
    Inflow Prior: Flow routing anchor yielding continuous upstream discharge Qin(t).
Drivers: ERA5-Land, GPM, Routing Yield: Qin(t)
04

Mass Conservation & Outflow

dS/dt = Qin(t) - Qout(t) + P(t) - ET(t) - Qloss
  • ▪
    Strict Residual Solver: Derives daily outflow Q*out from dS/dt = dV/dt.
  • ▪
    Physical Clamping: Enforces 0 ≤ Qout ≤ Qcapacity, preventing negative flows or false spikes.
  • ▪
    Zero Residual Verification: Verifies continuous daily mass balance across the full record.
Constraint: 0 ≤ Qout ≤ Qcap Yield: Q*out(t), ΔS(t)
